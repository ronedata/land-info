# Land Info — বাংলাদেশের ভূমি হিসাবের ফ্রি টুল

জমি পরিমাপ, খতিয়ান হিসাব, উত্তরাধিকার বণ্টন ও দলিল খরচের **১৬টি টুল** — সম্পূর্ণ
ফ্রি, লগইন ছাড়া, সবটাই ব্রাউজারে।

**🔗 <https://ronedata.github.io/land-info/>**

> কোনো পেমেন্ট নেই · কোনো রেজিস্ট্রেশন নেই · কোনো সার্ভারে ডেটা যায় না —
> প্রতিটি হিসাব আপনার নিজের ব্রাউজারেই হয়।

## টুলগুলো

**উত্তরাধিকার**
- **মুসলিম ফরায়েজ** — ৩৩ ধরনের উত্তরাধিকারী, আওল · রদ · আসাবা · হাজব ·
  উমারিয়্যাতাইন · মুনাছাখা। দাফন-কাফন, ঋণ ও ওসিয়তের ১/৩ সীমা বাদ দিয়ে হিসাব।
  A4 উত্তরাধিকার সনদ প্রিন্ট।
- **হিন্দু দায়ভাগ** — বাংলাদেশে প্রযোজ্য অসংহিতাবদ্ধ দায়ভাগ মত +
  সম্পত্তিতে হিন্দু মহিলার অধিকার আইন, ১৯৩৭। সীমিত স্বত্ব চিহ্নিত করে।

**খতিয়ান ও হিস্যা**
- **খতিয়ান বিশ্লেষণ (পর্চার হিসাব)** — একাধিক দাগ × একাধিক মালিক একসাথে।
  দাগভিত্তিক যোগফল **হুবহু** মেলে (largest-remainder সমন্বয়)।
- খতিয়ান হিস্যা বিশ্লেষণ · হিস্যা ক্যালকুলেটর · দাগের মধ্যে অংশ · তফসিল বন্টন

**পরিমাপ ও রূপান্তর**
- **জমি পরিমাপ ক্যানভাস** — ৩ থেকে ১২ বাহু। বাহু ও কর্ণ থেকে সঠিক জ্যামিতিতে
  আকৃতি বের করে (গড় পদ্ধতির ভুল এড়িয়ে), A4 প্রতিবেদন সহ।
- একক পরিবর্তন · আনা-গণ্ডা কনভার্টার · অনুপাত ক্যালকুলেটর · জমির সকল সূত্র

**দলিল ও ম্যাপ**
- **দলিল রেজিস্ট্রেশন খরচ** — ২৮ ধরনের দলিল, নিবন্ধন অধিদপ্তরের অফিসিয়াল
  সারণি ০১–০৫ অনুযায়ী (হার প্রকাশ: ১৬ সেপ্টেম্বর ২০২৫)।
- **সারাদেশের মৌজা ম্যাপ** — ১,৯৪,৩১৭ ফাইলের খোঁজা ও ডাউনলোড
- **মৌজা মূল্য তালিকা** · প্যান্টোগ্রাফ (ম্যাপ তুলনা) · প্রিন্ট স্টুডিও

## ★ কাঠার মাপ পরিবর্তনযোগ্য

বাংলাদেশে **কাঠার মাপ এলাকাভেদে আলাদা** — কোথাও ১ কাঠা = ৭২০ বর্গফুট (১.৬৫ শতক),
কোথাও ২.৬০ শতক। এই সাইটে কাঠা/বিঘা কোথাও হার্ডকোড করা নেই; একক পরিবর্তন টুল থেকে
নিজের এলাকার মাপ বসিয়ে নিলে **সব টুলে** সেটাই প্রযোজ্য হয়।

স্থির থাকে শুধু: ১ একর = ১০০ শতক = ৪৩,৫৬০ বর্গফুট · ১ শতক = ৪৩৫.৬ বর্গফুট ·
২০ কাঠা = ১ বিঘা।

## চালানো

কোনো build step নেই, npm নেই, framework নেই — শুধু HTML + CSS + JavaScript।

```bash
git clone https://github.com/ronedata/land-info.git
cd land-info
python -m http.server 8899
# → http://127.0.0.1:8899/
```

`index.html` সরাসরি ব্রাউজারেও খোলে, তবে **মৌজা মূল্য** ও **মৌজা ম্যাপ** টুল
`file://` এ চলবে না (CORS) — তখন উপরের মতো লোকাল সার্ভার লাগবে।

`#tool=<id>` দিয়ে সরাসরি কোনো টুল খোলা যায়, যেমন
[`#tool=farayeiz`](https://ronedata.github.io/land-info/#tool=farayeiz)।

## গঠন

```
index.html          সব UI, প্রতিটি টুল একটা modal
css/style.css       ডিজাইন সিস্টেম (CSS variables, ডার্ক মোড)
css/faraiz.css      শেয়ার্ড মোবাইল-ফার্স্ট UI (.fz-*)
css/print.css       A4 সনদ ও বিবরণী (.pr-*)
js/calculators.js   LandMath — বিশুদ্ধ গণিত, DOM ছোঁয় না
js/app.js           AppController — সব UI লজিক + ফরায়েজ ইঞ্জিন
js/*.js             প্রতিটি বড় টুলের নিজস্ব DOM-মুক্ত ইঞ্জিন
data/mouza-map/     মৌজা ম্যাপের ইনডেক্স (tree.json + শার্ড)
```

গণিতের অংশ DOM থেকে আলাদা রাখা হয়েছে, তাই Node দিয়ে সরাসরি যাচাই করা যায় —
**৫৫৭টি টেস্ট** আছে (এই রিপোতে নেই, ডেভেলপমেন্ট রিপোতে)।

## নির্ভুলতা প্রসঙ্গে

হিসাবের নিয়মগুলো অফিসিয়াল উৎস থেকে নেওয়া — নিবন্ধন অধিদপ্তরের ফি সারণি,
MFLO ১৯৬১, ১৯৩৭ সালের আইন। তবু **এটি আইনি পরামর্শ নয়**। দলিল, নামজারি বা
আদালতের কাজে ব্যবহারের আগে সংশ্লিষ্ট দপ্তর বা আইনজীবীর সাথে মিলিয়ে নেবেন।

ভুল পেলে issue খুলুন — বিশেষ করে হিসাবের ভুল হলে, কারণ এতে মানুষের আর্থিক
ক্ষতি হতে পারে।
