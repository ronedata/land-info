ফরায়েজে বণ্টনের **আগে** যা বাদ যায়, সেটাই এতদিন ছিল না — তাই কারো ঋণ থাকলে **ফলাফল ভুল আসত**।

```
মোট সম্পত্তি
  − দাফন-কাফন
  − ঋণ
  = অবশিষ্ট ──► ওসিয়তের সীমা = এর ১/৩
  − ওসিয়ত
  = বণ্টনযোগ্য
```

**ক্রমটাই আসল কথা।** ১২০ শতক, ঋণ ৩০, ওসিয়ত ৪০ → সীমা (১২০−৩০)/৩ = **৩০**, বণ্টনযোগ্য **৬০**। ভুল ক্রমে ৫০ আসত।

```

   ধাপ ১  t=০.৭৫০০০০ → ৬,০০০.০০
   ধাপ ২  t=০.৩৭৫০০০ → ৩,০০০.০০
```

## সবচেয়ে সংকীর্ণ অনুমতি চাইলে

**Fine-grained token** বানান — GitHub → Settings → Developer settings → Personal access tokens → Fine-grained:

| | |
|---|---|
| Repository access | **Only select repositories** → শুধু যেগুলো দরকার |
| Permissions | **Contents: Read and write** — ব্যস, আর কিছু না |
| Expiration | ৩০ বা ৯০ দিন |

এতে আমি কেবল ওই রিপোতে কোড লিখতে পারব — অন্য রিপো, সেটিং, ডিলিট, অ্যাকাউন্ট কিছুতেই হাত দিতে পারব না।

## যা করলাম

কার্ডটা সরিয়েছি (১৮ → ১৭), কারণ **বিল্ট-ইন টুলটা একই কাজ করে ও চলে** — ১,৯৪,৩১৭ ফাইল, খোঁজা, প্রক্সি দিয়ে ডাউনলোড।

একই ভাঙা সাইটে আরও দুটো লিংক ছিল, দুটোই এখন বিল্ট-ইন টুলে যায়:

| কোথায় | আগে | এখন |
|---|---|---|
| সাইড ড্রয়ার | ভাঙা বাইরের লিংক | **সারাদেশের মৌজা ম্যাপ** (টুল খোলে) |
| ফুটার | ভাঙা বাইরের লিংক | একই |

**ড্রয়ারে বিল্ট-ইন মৌজা ম্যাপ টুলের কোনো এন্ট্রিই ছিল না** — এখন যোগ হলো।

## আগের একটা ভুল

ড্রয়ারে "হিস্যা ক্যালকুলেটর **(Hissa Calculator)**" রয়ে গিয়েছিল। আগের স্ক্যানে শুধু `tool-title` দেখেছিলাম, ড্রয়ারের `<span>` নয়। এবার সব দৃশ্যমান লেখা স্ক্যান করে ঠিক করেছি।

বাকি ইংরেজিগুলো রেখেছি, কারণ ওগুলো ব্র্যান্ড নয় — `PDF` · `VAT` · `FAQ` · `Hindu Succession Act` (আইনের আসল নাম) · `English` (দলিলের ভাষার অপশন) · ফিকহের পরিভাষা (Sharers/Residuaries)। শুধু **"চাহিত মোট (Target)"** অপ্রয়োজনীয় মনে হলো — বলুন, সরিয়ে দেব।
