# ★ সবচেয়ে বেশি লাভের দুটো

## ১. ক্ষেত্রফল / অজানা বাহু — সবচেয়ে সহজ

আসল বৈশিষ্ট্য একটাই টগল: **বন্ধ** = বাহু → ক্ষেত্রফল · **চালু** = ক্ষেত্রফল + বাকি বাহু → **অজানা বাহু**। উল্টো হিসাবটাই ওদের বাড়তি।

১৫ আকৃতির ১৪টা আমাদের আছে। **শুধু একটা নতুন** — "বাঁকা জমি (Segment)":

```
r = (c² + 4h²) / (8h)
θ = 2·asin(c / 2r)
A = ½ r² (θ − sin θ)
```

`LandFormula.svg` এর ডায়াগ্রামও পুনর্ব্যবহার হবে। **আমাদের বাড়তি দেওয়ার সুযোগ:** ডায়াগ্রামে ইনপুট করা মাপ লেবেল হিসেবে বসানো, কাঠার ভিত্তি, A4 প্রিন্ট, অজানা বাহুর দুটো সমাধান থাকলে দুটোই দেখানো।

## ২. জমির ভাগ-বন্টন — ওদের অ্যালগরিদম ফাঁস হয়ে গেছে

ওদের **"বন্টনের গাণিতিক প্রমাণ"** অংশ নিজেই পুরো পদ্ধতি দেখিয়ে দেয়:

```
টার্গেট → বর্গফুট (×৪৩৫.৬)
প্যারামিটার t ∈ (০,১) এর উপর বাইসেকশন — ~১১ ইটারেশনে মেলে
প্রতি ধাপে ক্ষেত্রফল = হিরণের সূত্রে দুই ত্রিভুজ
নতুন আইল = দূরত্ব সূত্র · যাচাইয়ের কর্ণ = কোসাইন সূত্র
```

আমাদের `solvePolygon()` ও `polygonArea()` আছেই — **নতুন ভারী গণিত লাগবে না**, শুধু bisection লুপ।

## ১. KMZ ফাইল — npm ছাড়া বানানো যায় ✅ প্রমাণিত

GroundOverlay: আছে ✓ · Icon href → ZIP এ আছে ✓
LatLonQuad   : ৪টি কোণা ✓

**~১২০ লাইন, শূন্য নির্ভরতা।** আমাদের "npm নেই" নীতি ভাঙতে হবে না।

**২ বিন্দু = শুধু scale + rotation।** স্ক্যান করা পুরনো মৌজা ম্যাপে প্রায়ই **তির্যকতা (skew)** ও কাগজ বাঁকার বিকৃতি থাকে — ২ বিন্দুতে সেটা ঠিক হয় না। ওদের পাতায় লেখা "**কমপক্ষে** দুটি" — তারাও বেশি নিতে পারে।
