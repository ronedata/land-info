# ৩. ক্ষেত্রফল / অজানা বাহু নির্ণয় (`area-calculator`) — PRO

⭐ **সবচেয়ে সহজ ও বেশি লাভের টুল।** আমাদের `js/land-formula.js` এ এই সব সূত্র
ইতিমধ্যেই আছে — শুধু ক্যালকুলেটরের মোড়ক আর ডায়াগ্রাম বসাতে হবে।

**স্ক্রিনশট:** `shots/area-00-shapes.png` (আকৃতির গ্রিড) ও প্রতিটি আকৃতির নিজস্ব ছবি।

## গঠন

```
ধাপ ১ — জমির আকৃতি নির্বাচন করুন      (৩ কলামের গ্রিড, ১৫টি কার্ড)
           ↓ কার্ডে ক্লিক
ধাপ ২ — "<আকৃতির নাম> পরিমাপ"          (ওই আকৃতির নির্দিষ্ট ঘরগুলো)
           ↓ "হিসাব করুন"
ধাপ ৩ — ফলাফল
```

কার্ডের HTML: `<div class="shape-card" data-shape="rectangle">` — অর্থাৎ
আকৃতি একটি data-attribute দিয়ে চেনানো হয়।

### ★ দুটো মোড — একটাই টগল

`#ac-calc-mode-toggle` (checkbox) — প্রতিটি আকৃতিতেই আছে।

- **বন্ধ:** বাহুগুলো দিয়ে **ক্ষেত্রফল** বের করা
- **চালু:** ক্ষেত্রফল + বাকি বাহু দিয়ে **অজানা বাহু** বের করা

এটাই টুলের আসল বৈশিষ্ট্য — "ক্ষেত্রফল/অজানাবাহু"। উল্টো হিসাবটাই ওদের বাড়তি।

ইনপুটের placeholder সবগুলোতেই **"পরিমাপ দিন"**, লেবেল নেই — ঘরের পরিচয় বোঝা যায়
`id` থেকে (নিচের সারণিতে)।

## ১৫টি আকৃতি ও তাদের ইনপুট

`id` এর গঠন: `ac-input-<key>`

| # | আকৃতি | ইনপুট (key) | ক্ষেত্রফলের সূত্র |
|:--:|---|---|---|
| ১ | আয়তক্ষেত্র | `l`, `w` | l × w |
| ২ | অনিয়মিত চতুর্ভুজ | `a`, `b`, `c`, `d`, `diag` | কর্ণ দিয়ে ২ ত্রিভুজ → হিরণ |
| ৩ | সমকোণী ট্রাপিজিয়াম | `a`, `b`, `h`, `s` | ½(a+b)h · `s` = হেলানো বাহু |
| ৪ | সাধারণ ত্রিভুজ | `a`, `b`, `c` | হিরণের সূত্র |
| ৫ | সাধারণ ট্রাপিজিয়াম | `b`, `a`, `h` | ½(a+b)h |
| ৬ | সমকোণী ত্রিভুজ | `b`, `h` | ½ × b × h |
| ৭ | বর্গক্ষেত্র | `a` | a² |
| ৮ | বাঁকা জমি (Segment) | `c`, `h` | বৃত্তীয় খণ্ড — `c` জ্যা, `h` উচ্চতা |
| ৯ | সম্পূর্ণ বৃত্ত | `r` | πr² |
| ১০ | অর্ধ-বৃত্তাকার জমি | `r` | ½πr² |
| ১১ | ৫ বাহু বিশিষ্ট জমি | `a`,`b`,`c`,`d`,`e`, `d1`,`d2` | ২ কর্ণ → ৩ ত্রিভুজ |
| ১২ | ৬ বাহু বিশিষ্ট জমি | `a`…`f`, `d1`,`d2`,`d3` | ৩ কর্ণ → ৪ ত্রিভুজ |
| ১৩ | রম্বস | `d1`, `d2` | ½ d1 d2 |
| ১৪ | সামান্তরিক | `b`, `h` | b × h |
| ১৫ | ডিম্বাকৃতি (Ellipse) | `l`, `w` | π × (l/2) × (w/2) |

**লক্ষণীয় — N বাহুর নিয়ম:** N বাহুর বহুভুজে **N−3 কর্ণ** লাগে।
৫ বাহু → ২ কর্ণ, ৬ বাহু → ৩ কর্ণ। আমাদের `LandCanvasEngine.solvePolygon()`
ঠিক এই নিয়মেই কাজ করে, তাই যুক্তি মিলে যাবে।

**"বাঁকা জমি (Segment)"** আমাদের সূত্রপাতায় নেই — নতুন যোগ করতে হবে:
```
বৃত্তীয় খণ্ডের ক্ষেত্রফল:
   r = (c² + 4h²) / (8h)
   θ = 2 · asin( c / (2r) )
   A = ½ r² (θ − sin θ)
```

## আমাদের বানানোর পরিকল্পনা

1. **ইঞ্জিন** — `js/area-calc.js` এ `AreaCalc` মডিউল (DOM-মুক্ত):
   - `SHAPES` — ১৫টি আকৃতির সংজ্ঞা: `{ id, name, inputs:[...], area(v), unknown(key, area, v) }`
   - প্রতিটির `area()` ও উল্টো `unknown()` — দুই মোডের জন্য
   - প্রান্তিক যাচাই: ত্রিভুজ অসমতা (a+b>c), `diag` বৈধ কি না, r>0 ইত্যাদি
2. **UI** — আকৃতির গ্রিড (`LandFormula.svg` এর ডায়াগ্রাম পুনর্ব্যবহার করা যাবে!)
   → ঘর → ফলাফল (শতক · কাঠা · বিঘা · একর · বর্গফুট, `LandMath.convertArea` দিয়ে)
3. **আমাদের বাড়তি সুবিধা যোগ করার সুযোগ:**
   - ডায়াগ্রামে ইনপুট করা মাপ **লেবেল হিসেবে বসিয়ে দেখানো**
   - কাঠার ভিত্তি (`.fz-katha-note`) — ওদের নেই
   - A4 প্রিন্ট
   - অজানা বাহুর একাধিক সমাধান থাকলে দুটোই দেখানো
4. **টেস্ট** — প্রতিটি আকৃতির `area()` ও `unknown()` উভয় দিকে
   (`area(unknown(k, A, v)) === A` — গোল-ট্রিপ যাচাই)
