# ৯. Map Converter + Cleaner (PDF ↔ JPG)

`pdf-to-jpg` — PRO

**স্ক্রিনশট:** `shots/pdf-to-jpg.png`

**PRO নয় — ফ্রি।** কিন্তু ম্যাপ-সংক্রান্ত সব টুলের (৫, ৬, ৭) ভিত্তি,
তাই আগে বানানো বুদ্ধিমানের কাজ।

## ওদের দাবি
> "ম্যাপের ১০০% CAD স্কেল ও মেটাডেটা সুরক্ষিত"

## ইনপুট
| ঘর | বিকল্প |
|---|---|
| থেকে (in-type) | PDF · JPG/PNG |
| রূপান্তর (TO) | JPG · PDF |
| রেজোলিউশন (DPI) | ১৫০ DPI (সাধারণ) · ৩০০ DPI (স্ট্যান্ডার্ড) · ৪০০ DPI (সর্বোচ্চ কোয়ালিটি) |
| ম্যাপ পরিষ্কার করুন | checkbox |

ড্র্যাগ-অ্যান্ড-ড্রপ: "পিডিএফ ফাইলটি এখানে আনুন বা ক্লিক করুন"
গ্রহণ করে: `application/pdf`

## ব্রাউজারেই সম্ভব
- **PDF → JPG:** pdf.js দিয়ে নির্দিষ্ট DPI-তে canvas এ রেন্ডার → `toBlob('image/jpeg')`
  (DPI → scale: `scale = DPI / 72`)
- **JPG → PDF:** ছবিকে PDF এ মোড়ানো — হাতে ন্যূনতম PDF লেখা যায়
  (আমরা `dolil-fee` এর জন্য PDF পার্স করেছি, লেখাও পারব)
- **ম্যাপ পরিষ্কার:** threshold দিয়ে সাদা/কালো আলাদা করা, ছোট দাগ (noise) মুছা,
  কনট্রাস্ট বাড়ানো — `getImageData` + Web Worker

## সতর্কতা
আমাদের নীতিতে **npm/CDN লাইব্রেরি নেই**। pdf.js CDN থেকে আনতে হবে
(Chart.js ও Bootstrap Icons যেভাবে আসে) — সেটা মেনে নেওয়া যায়,
নয়তো এই টুল বাদ দিতে হবে।
