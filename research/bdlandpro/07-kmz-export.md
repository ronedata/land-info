# ৭. গুগল ম্যাপে জমির দাগ — KMZ এক্সপোর্ট

`mouza-map-on-google-map` — PRO

**স্ক্রিনশট:** `shots/mouza-map-on-google-ma.png`

মৌজা ম্যাপকে Google স্যাটেলাইট ছবির সাথে মিলিয়ে বসিয়ে **KMZ** ফাইল বানায়,
যা Google Earth এ খোলা যায়।

## ওদের নিজের বর্ণনা
> "মৌজা ম্যাপকে Google Maps স্যাটেলাইট ভিউয়ের সাথে ক্যালিব্রেট করে KMZ ফাইল
> তৈরি করুন। **কমপক্ষে দুটি নিয়ন্ত্রণ বিন্দু** ব্যবহার করে ম্যাপটি সঠিক
> অবস্থানে বসানো হবে।"

## অংশ
`গুগল ম্যাপ ফাইল এক্সপোর্ট` · `মৌজা ম্যাপ সিলেক্ট করুন` · `মৌজা ম্যাপ আপলোড করুন`

Google Maps API ব্যবহার করে (`usesMap: true`)। ফাইল: `image/*`, `application/pdf`

## গণিত
২টি নিয়ন্ত্রণ বিন্দু (ছবির পিক্সেল ↔ অক্ষাংশ/দ্রাঘিমাংশ) থেকে
similarity transform (scale + rotation + translation) বের হয়।
৩+ বিন্দু হলে least-squares affine ভালো।

KMZ = ZIP এর ভেতরে `doc.kml` + ছবি। KML এ `<GroundOverlay>` দিয়ে
`<LatLonBox>` (north/south/east/west + rotation) বসাতে হয়।
**ব্রাউজারেই সম্ভব** — ZIP বানাতে লাইব্রেরি লাগবে (আমাদের নীতি: npm নেই,
তাই হাতে ZIP (stored, কম্প্রেশন ছাড়া) লিখতে হবে — কঠিন কিন্তু সম্ভব)।

## কঠিন যেখানে
- Google Maps API key লাগবে (ফ্রি টিয়ারে সীমা আছে) — বিকল্প: Leaflet + OSM/Esri টাইল
- ZIP লেখা npm ছাড়া
