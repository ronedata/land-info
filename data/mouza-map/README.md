# মৌজা ম্যাপ ইনডেক্স — নতুন করে তৈরি

**তারিখ:** ৩০ জুলাই ২০২৬
**উৎস:** ইউজারের নিজের Drive (`ronedata/map` রিপোর সাথে যুক্ত Apps Script দিয়ে ক্রল করা)

---

## কেন দরকার হলো

`ronedata/map` রিপোর `Data/*.json` এর **ফোল্ডার ও ফাইল আইডি পুরনো হয়ে গেছে** —
Drive এ ফাইলগুলো নতুন করে আপলোড/সরানো হয়েছে কিন্তু ইনডেক্স হালনাগাদ হয়নি।

```
সিলেট বিভাগের আইডি
   পুরনো JSON : 1onqdMV2pvh91kBsTDiLuSsbuRrAgnAj7
   লাইভ Drive : 1bFJVN63vOKnpf8b74Re3A0n59o_L4xYR   ← মেলে না
```

ফলে ডাউনলোড করতে গেলে আসে —
*"প্রদত্ত আইডি দিয়ে কোনও আইটেম খুঁজে পাওয়া যায়নি।"*

**অর্থাৎ map সাইটে এখন ডাউনলোড কাজ করছে না।**

## দুই রকম ফরম্যাট

### `compat/` — map সাইটের জন্য (৪৪.৭ MB, ৮ ফাইল)

পুরনো ফরম্যাট **হুবহু** — `ronedata/map` এর `Data/` ফোল্ডারে এই ৮টি ফাইল
বদলে দিলেই **সাইটের কোড না ছুঁয়েই ডাউনলোড ঠিক হয়ে যাবে**।

দুটো নতুন ফিল্ড যোগ হয়েছে (পুরনো কোড এগুলো উপেক্ষা করবে, কিছু ভাঙবে না):
- `subPath` — জরিপ ফোল্ডারের নিচে ফাইলটি কোথায় ছিল
- `tooBig: true` — ৩৫ MB এর বড়, প্রক্সিতে চলবে না
- `rawName` — জরিপ ফোল্ডারের আসল নাম (স্বাভাবিক করার আগে)

### `tree.json` + `files/` — Land Info এর জন্য

```
tree.json          ০.১৪ MB   বিভাগ/জেলা/উপজেলা/জরিপ — ফাইল ছাড়া
files/<id>.json    ১,০১২টি   ওই ফোল্ডারের ফাইল, চাহিদামতো লোড
```

ঢাকার ১৪ MB একসাথে টানতে হবে না — যে জরিপ-ফোল্ডার খোলা হবে কেবল তারটাই আসবে।

## ⚠️ যে সীমাগুলো মনে রাখতে হবে

1. **২১৭টি ফাইল প্রক্সিতে চলবে না** (>৩৫ MB)। Apps Script এর রেসপন্স সীমা
   ~৫০ MB, base64 আকার ১.৩৩× বাড়ায়। সবচেয়ে বড় — **৭১৯.৮ MB**
   (`scan__2013-04-01_06-24-09.pdf`, দিনাজপুর/বীরগঞ্জ)।
   ইনডেক্সে `tooBig: true` দিয়ে চিহ্নিত — টুলে "Drive এ খুলুন" দেখানো উচিত।

2. **Drive ফাইল পাবলিক নয়** — `uc?export=view` ৪০৩, `/preview` ৪০১ দেয়।
   তাই **একমাত্র পথ Apps Script প্রক্সি** (`?action=download&fileId=…`),
   যেটির CORS `*` — ব্রাউজার থেকে সরাসরি ডাকা যায়। বাইট আসে base64 এ,
   ফলে ক্যানভাসে বসানো যাবে (Basics Measure / ম্যাপ জয়েন্ট / KMZ সম্ভব)।

3. **Apps Script কোটা** — ফ্রি অ্যাকাউন্টে দৈনিক সীমা আছে। সাইট জনপ্রিয় হলে
   ছুঁয়ে যাবে। প্রতি ফাইলে ১০ MB × ১.৩৩ = ১৩ MB ট্রান্সফার — মোবাইলে ভারী।

4. **ফাইলের নাম অনন্য নয়** — `1-1.jpg` ৩৬ বার, `19-1.jpg` ৩৫ বার আছে।
   মৌজার নাম ফাইলের নাম থেকে বের করা যাবে না, **ফোল্ডারের পথই ভরসা**।

5. **জরিপের নাম ৭১ রকম ছিল** — `RS 1`, `BS_RS 1`, `সিএস বগুড়া`,
   এমনকি উপজেলার নাম (`Bera`, `PABNA`)। স্বাভাবিক করে **১৬টিতে** নামানো হয়েছে;
   আসল নাম `rawName` এ রাখা আছে।

## আবার ক্রল করতে হলে

স্ক্রিপ্ট দুটি এই ফোল্ডারে রাখা হয়নি (স্ক্র্যাচপ্যাডে ছিল)। পদ্ধতি:

1. `listChildren` API রুট `1T1GWNPpszx44Mj42u7tLXaP3ac3t4yRb` থেকে শুরু করে
   BFS — প্রতিটি ফোল্ডারে একটি কল, ৫টি সমান্তরাল, ব্যর্থ হলে ব্যাকঅফ
2. ফল লাইনে লাইনে `crawl-cache.jsonl` এ লিখলে **পুনরারম্ভযোগ্য** হয়
3. মোট ৩,৯৪১ ফোল্ডার · **৫৫ মিনিট** লেগেছিল

Drive এ নতুন ম্যাপ যোগ হলে আবার চালাতে হবে।
